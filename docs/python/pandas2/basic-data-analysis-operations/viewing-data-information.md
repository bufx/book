# Pandas2数据信息查看操作

DataFrame的基础信息和统计性信息。在我们拿到一个数据集，用Pandas载入后，需要做一些初步的验证，比如行名、列名是否一致，数据量是否有缺失，各列的数据类型等，让我们对数据的全貌有所了解。大多数功能对Series也是适用的。

## 查看样本信息

加载完的数据可能由于量太大，我们需要查看部分样本数据，

Pandas2提供了三个常用的样式查看方法。

* `df.head()`：前部数据，默认5条，可指定条数。可指定参数，查看具体条数；
* `df.tail()`：尾部数据，默认5条，可指定条数。可指定参数，查看具体条数；
* `df.sample()`：一条随机数据，可指定条数。

```python
# 导入pandas库，去别名pd
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.head())
print(df.tail())
print(df.sample(3))
```

## 查看数据形状

执行df.shape会返回一个元组，该元组的第一个元素代表行数，第二个元素代表列数，这就是这个数据的基本形状，也是数据的大小。

```python
# 导入pandas库，去别名pd
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.shape)

#======输出======
(100, 7)
```

## 查看数据类型信息

df.dtypes会返回每个字段的数据类型及DataFrame整体的类型。如果是Series，需要用s.dtype:

```python
# 导入pandas库，去别名pd
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.dtypes)

#======输出======
姓名        str
学号        str
出生日期      str
性别        str
语文分数    int64
数学分数    int64
英语分数    int64
dtype: object
```

## 查看行列索引内容

df.axes会返回一个列内容和行内容组成的列表[列索引, 行索引]。

```python
# 导入pandas库，去别名pd
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.axes)

#======输出======
[RangeIndex(start=0, stop=100, step=1), Index(['姓名', '学号', '出生日期', '性别', '语文分数', '数学分数', '英语分数'], dtype='str')]
```
