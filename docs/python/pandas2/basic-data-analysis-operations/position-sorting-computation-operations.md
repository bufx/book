# Pandas2位置排序计算操作

介绍几个经常用到的位置计算操作。`diff()`和`shift()`经常用来计算数据的增量变化，`rank()`用来生成数据的整体排名。

## 位置差值diff()函数操作

`df.diff()`可以做位移差操作，经常用来计算一个序列数据中上一个数据和下一个数据之间的差值，如增量研究。

默认被减的数列下移一位，原数据在同位置上对移动后的数据相减，得到一个新的序列，第一位由于被减数下移，没有数据，所以结果为NaN。

可以传入一个数值来规定移动多少位，负数代表移动方向相反。

Series类型如果是非数字，会报错；

DataFrame会对所有数字列移动计算，同时不允许有非数字类型列。

diff方法语法：`diff(periods=1, axis=0)`

*   **periods**：差值步长，默认 `1`（计算相邻元素的差值）。正数表示向前查找，负数表示向后查找。
*   **axis**：计算方向，默认 `axis=0`（沿行方向，即上下行差值），设置为 `axis=1` 时计算列之间的差值。

### Series示例

```python
import pandas as pd

s1 = pd.Series([5, 7, 1, 6, 9, 2])
print(s1.diff())

#======输出======
0    NaN
1    2.0
2   -6.0
3    5.0
4    3.0
5   -7.0
dtype: float64
```

### Dataframe示例

查询前10条数据，只分析语文分数和数学分数，默认上下之间比，步长1;

## 位置移动shift()函数操作

`shift()`可以对数据进行移位，不做任何计算，也支持上下左右移动，移动后目标位置的类型无法接收的为NaN。

语法：`DataFrame.shift(periods=1, freq=None, axis=0)`

*   **periods**：移动的步数（默认 `1` ）。
    *   正数表示 **向下或向右** 移动，负数表示 **向上或向左** 移动。
*   **freq**：可选参数，仅适用于时间序列。指定偏移量（如 `'D'` 表示按天移动），此时会调整索引而非数据。
*   **axis**：移动方向（默认 `axis=0`，即沿行移动，`axis=1`，沿列移动，向右移动）。

我们来看一个示例，数据向下移动2位

## 排序rank()函数操作

pandas 的 `rank()` 方法用于对数据进行 **排序并分配排名**，支持处理重复值、缺失值（NaN）以及多种排名策略。它在数据分析、竞赛得分排名、金融数据排序等场景中非常实用。以下是详细解析：

```python
DataFrame.rank(
    axis=0,               # 沿行(axis=0)或列(axis=1)计算排名
    method='average',     # 处理重复值的策略
    numeric_only=None,    # 是否仅对数值型数据排名
    na_option='keep',     # 缺失值处理方式
    ascending=True,       # 是否升序排序
    pct=False             # 是否返回百分比排名
)
```

**核心参数详解**

**1. method: 处理重复值的策略**

*   **average** (默认): 重复值分配平均排名（如并列第2和3名，均得2.5）。
*   **min**: 重复值分配最小可能排名（如并列第2和3名，均得2）。
*   **max**: 重复值分配最大可能排名（如并列第2和3名，均得3）。
*   **first**: 按数据出现的顺序分配唯一排名（无重复）。
*   **dense**: 类似 `min`，但排名之间不跳数（如1, 2, 2, 3）。

**2. ascending: 排序方向**

*   `True` (默认): 升序（值越小排名越小）。
*   `False`: 降序（值越大排名越小）。

**3. na_option: 缺失值处理**

*   **keep** (默认): 保留NaN，排名为NaN。
*   **top**: 将NaN视为最小值，排名靠前。
*   **bottom**: 将NaN视为最大值，排名靠后。

**4. pct: 百分比排名**

*   `True`: 返回排名占总数的百分比（如排名1/4得0.25）。
*   `False` (默认): 返回绝对排名值。

我们来看一个排名示例，用pandas rank()方法实现语文分数的排名(**最后一列多了语文排名**):

# 导入pandas库，去别名pd

df = pd.read_csv('../student_scores.csv')

# 对语文分数进行排名，排名方法为最小排名，排名为浮点数。
df['语文排名'] = df['语文分数'].rank(method='min', ascending=False)
print(df)

print("----------")
# 转换为整数类型,保留整数部分。
df['语文排名'] = df['语文排名'].astype(int)
print(df)
