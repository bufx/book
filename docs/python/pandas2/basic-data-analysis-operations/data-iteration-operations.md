# Pandas2数据迭代操作

数据迭代和数据遍历都是按照某种顺序逐个对数据进行访问和操作，在Python中大多由for语句来引导。Pandas中的迭代操作可以将数据按行或者按列遍历，我们可以进行更加细化、个性化的数据处理。

## 迭代Series

Series本身是一个可迭代对象，可迭代单列，也可以迭代索引和指定的多列，使用Python内置的zip函数将其打包为可迭代的zip对象

示例：

```python
import pandas as pd

df = pd.read_excel('../student_scores.xlsx')  # 读取excel，返回DataFrame数据集对象

print(df)
print('------------------')

# 迭代单列
for name in df.姓名:
    print(name)
print('------------------')

# 迭代索引和指定的多列
for i, n, m in zip(df.index, df.姓名, df.数学分数):
    print(i, n, m)
```

## 迭代DataFrame

### iterrows()迭代器

`iterrows()` 是 pandas 中用于**逐行遍历** DataFrame 的方法，它返回一个生成器，每次迭代提供行的索引和行数据（以 Series 形式）。以下是详细解析：

基本语法：

```python
for index, row in df.iterrows():
    # 处理每一行
    print(index, row['列名'])
```

*   **返回值**：每次迭代返回一个元组 `(index, row)`。
    *   `index`：当前行的索引（可能是整数或自定义标签）。
    *   `row`：当前行的数据，以 `Series` 形式存储。

示例：

```python
import pandas as pd

# 创建示例 DataFrame
data = {'A': [1, 2, 3], 'B': ['x', 'y', 'z']}
df = pd.DataFrame(data)
print(df)
print('------------------')

# 遍历每一行
for idx, row in df.iterrows():
    print(f"Index: {idx}, A: {row['A']}, B: {row['B']}")

#======输出======
   A  B
0  1  x
1  2  y
2  3  z
------------------
Index: 0, A: 1, B: x
Index: 1, A: 2, B: y
Index: 2, A: 3, B: z
```

### itertuples()迭代器

`itertuples()` 是 pandas 中用于高效**逐行遍历** DataFrame 的方法，返回 `namedtuple` 对象（默认）或普通元组。相比 `iterrows()`，它在速度和内存占用上表现更优，适合处理中等规模的数据集。

语法：

```python
for row in df.itertuples(index=True, name='Pandas'):
    # 处理每一行
    print(row.Index, row.列名)
```

参数说明

| 参数    | 说明                                                         |
| :------ | :----------------------------------------------------------- |
| `index` | 是否包含行索引，默认为 `True`。索引作为返回对象的第一个元素。 |
| `name`  | 定义返回的 `namedtuple` 名称，默认为 `'Pandas'`。设为 `None` 返回普通元组。 |

返回类型namedtuple，每行数据封装为一个命名的元组，可通过属性（如 `row.A`）访问列值。

我们看一些示例：

```python
import pandas as pd

df = pd.read_excel('../../student_scores.xlsx')  # 读取excel，返回DataFrame数据集对象

print(df)
print('------------------')

for row in df.itertuples():
    print(row)

print('------------------')
# 不需要索引列
for row in df.itertuples(index=False):
    print(row)

print('------------------')
# 通过row.属性 打印列数值
for row in df.itertuples():
    print(row.Index, row.姓名)

print('------------------')
# 查询出语文大于90分，数学大于80分的人
for row in df.itertuples():
    if row.语文分数 > 90 and row.数学分数 > 80:
        print(row.姓名, row.语文分数, row.数学分数)
```

### items()迭代器

`items()` 是 pandas 中用于**按列遍历** DataFrame 的方法，返回一个生成器，每次迭代提供列名和对应列的 Series 数据。该方法适用于需要逐列处理数据的场景，例如统计列级指标或应用列级转换函数。

语法：

```python
for column_name, column_data in df.items():
    # 处理每一列
    print(column_name, column_data.mean())
```

参数

*   **无显式参数**：`items()` 方法默认遍历所有列，无需额外配置。

**2. 返回值**

*   **每次迭代返回一个元组** `(column_name, column_data)`：
    *   `column_name`：当前列的列名（字符串类型）。
    *   `column_data`：当前列的数据，以 `Series` 形式存储。

示例：

```python
import pandas as pd

df = pd.read_excel('../../student_scores.xlsx')  # 读取excel，返回DataFrame数据集对象

print(df)
print('------------------')

for col_name, col_data in df.items():
    print('列名:', col_name)
    print('列数据:')
    print(col_data)
    print('==================')

print('------------------')
# 做一些列统计
for col_name, col_data in df.items():
    if col_name == '语文分数' or col_name == '数学分数' or col_name == '英语分数':
        print(col_name, '平均分', col_data.mean(), '最高分', col_data.max(), '最低分', col_data.min())
```
