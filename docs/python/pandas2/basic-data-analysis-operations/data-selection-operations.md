## 基于行和列选择切片

### 基于行切片

DataFrame 的默认行切片语法 `df[start:end:step]` 基于 **行位置**（类似 Python 列表切片），但需注意以下特性：

*   **包含起始位置，不包含结束位置**（与 Python 切片一致）。
*   **索引无关性**：仅依赖行位置（0-based），与 DataFrame 的实际行标签无关。
*   **返回新视图**：切片返回的是原数据的视图（非副本），修改可能影响原数据。

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df[1:5]) # 获取第2行到第5行数据，默认步长1
print("----------")
print(df[1:5:2]) # 获取第2行到第5行数据，默认步长2
print("----------")
print(df[:5]) # 前5行数据
print("----------")
print(df[:]) # 获取所有数据
print("----------")
print(df[::-1]) # 反转顺序
```

## 基于标签的切片:loc[]

`df.loc[]` 基于 **行和列的标签** 进行切片，语法为 `df.loc[row_labels, col_labels]`，规则如下：

*   **闭区间**：切片包含起始和结束标签（与默认切片不同）。
*   **支持混合类型**：行/列标签可以是数字、字符串、时间等。
*   **灵活组合**：可同时选择行和列。

我们通过下面几个示例来学习下：

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.loc[1]) # 返回索引标签是1的行 返回类型是Series
print("----------")
print(df.loc[[2,4,8]]) # 返回索引标签是2, 4,8的行
print("----------")
print(df.loc[:]) # 查询所有
print("----------")
print(df.loc[2:10]) # 查询索引标签2到10的行，包括10
print("----------")

# 设置索引标签，loc里面可以是字符串参数
print(df.set_index('姓名').loc['钱fY'])
print("----------")

# 筛选行的时候，还要筛选列
print(df.loc[2:10, ['姓名', '语文分数']]) # 查询索引标签2到10的行，包括10，只分析姓名和语文分数
print("----------")
```

## 基于位置的切片:iloc[]

`df.iloc[]` 基于 **行和列的位置**（0-based 索引）切片，语法为 `df.iloc[row_positions, col_positions]`，规则如下：

*   **左闭右开**：不包含结束位置（与 Python 切片一致）。
*   **纯数字索引**：仅接受整数位置，与标签无关。

我们几个实例来学习下：

```python
print(df.iloc[:]) # 所有数据
print("----------")
print(df.iloc[2:10:2]) # 2到10, 步长2
print("----------")
print(df.iloc[2:10, [1, 3]]) # 2到10, 第1和第3列
```

## 基于标签取具体值:at[]

`at` 是 Pandas 中用于快速访问或修改 **单个元素** 的高效方法，特别适用于通过行和列的 **标签名** 直接定位数据。与 `loc` 和 `iloc` 相比，`at` 在单元素操作中性能更优，但仅支持标量值操作。以下是详细解析：

**一、`at` 的核心特性**

**1. 基于标签索引**

通过行索引标签和列标签定位元素，与 `loc` 类似，但仅支持单元素操作。

**2. 高效访问**

直接通过哈希表定位元素，避免 `loc` 的通用索引检查，性能更高。

**3. 原地修改**

修改操作会直接影响原始 DataFrame，不生成副本。

**4. 仅支持标量**

不能用于选择多行或多列，仅限单个元素。

我们看下具体示例：

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.at[2, '学号']) # 取 行索引为2，列索引为学号 的精确值
print("----------")
print(df.姓名.at[2]) # 取 行索引为2，列索引为姓名 的精确值
print("----------")
print(df.loc[2].at['姓名']) # 取 行索引为2，列索引为姓名 的精确值
print("----------")
print(df.set_index('学号').at['s87189', '姓名']) # 取索引为s87189的姓名 的精确值
print("----------")
print(df.set_index('学号').姓名.at['s87189']) # 取索引为s87189的姓名 的精确值

#======输出======
s60881
----------
吴Km
----------
吴Km
----------
孙ag
----------
孙ag
```

## 基于位置取具体值:iat[]

`iat` 是 Pandas 中用于 **基于位置快速访问或修改单个元素** 的高效方法。与 `iloc` 类似，但 `iat` 专为单元素操作设计，性能更优。以下是其核心用法、示例及注意事项：

**一、核心特性**

**1. 基于整数位置索引**

通过行和列的 **位置**（从 0 开始）访问元素，与标签无关。

**2. 高效访问**

直接计算内存位置，跳过索引检查，性能优于 `iloc`。

**3. 仅支持标量操作**

不可用于多行、多列或切片操作。

**4. 原地修改**

修改操作直接影响原始 DataFrame，不生成副本。

我们来看下示例：

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.iat[2, 0]) # 取 行索引为2，列索引为0 的精确值
print("----------")
print(df.loc[2].iat[0]) # 取 行索引为2，列索引为0 的精确值

#======输出======
吴Km
----------
吴Km
```

## 获取数据get方法

`get` 是 Pandas 中一个 **安全访问数据** 的方法，其行为类似于 Python 字典的 `get` 方法，用于在键（列名或索引）不存在时返回默认值而非抛出错误。它适用于需要避免 `KeyError` 的灵活数据访问场景。

**一、`get` 方法的核心特性**

**1. 安全访问**：当键不存在时返回默认值（默认为 `None`），而非抛出异常。

**2. 简洁性**：简化对列或索引值的条件判断。

**3. 适用对象**：

*   **DataFrame**：通过列名获取列（返回 `Series`）。

- **Series**：通过索引/标签获取值（返回标量）。

**4. 默认值支持**：可自定义缺失键时的返回值。

**二、语法与参数**

**1. DataFrame 的 `get`**

```python
df.get(key, default=None)
```

*   **参数**：
    *   `key`：列名（字符串）。
    *   `default`：键不存在时的返回值（默认 `None`）。
*   **返回值**：
    *   如果列存在：返回对应的 `Series`。
    *   如果列不存在：返回 `default` 值。

**2. Series 的 `get`**

```python
series.get(key, default=None)
```

*   **参数**：
    *   `key`：索引标签。
    *   `default`：标签不存在时的返回值。
*   **返回值**：
    *   如果标签存在：返回对应的标量值。
    *   如果标签不存在：返回 `default` 值。

我们来看下示例：

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.get('姓名', '没找到'))
print("----------")
print(df.get('姓名2', '没找到'))
print("----------")
print(df.set_index('学号').姓名.get('S80742', '没找到'))

#======输出======

1     王Mu
2     吴Km
```

## 数据截取:truncate

`truncate` 是 Pandas 中用于 **按索引标签范围截断数据** 的方法，适用于快速保留指定区间内的行或列，尤其适合处理时间序列或有序索引的数据。以下是其核心用法、参数说明及示例：

**一、核心功能与特性**

**1. 按索引范围截断**：基于行或列的索引标签（而非位置），保留 `before` 到 `after` 之间的数据。

**2. 支持双向截断**：可同时指定起始（`before`）和结束（`after`）标签，或只指定其一。

**3. 适用场景**：

*   时间序列数据（如按日期范围截断）。
*   有序索引的 DataFrame 或 Series（需索引已排序）。

**4. 轴灵活性**：默认沿行方向（`axis=0`）截断，也可对列操作（`axis=1`）。

**二、语法与参数**

```python
DataFrame.truncate(before=None, after=None, axis=None, copy=True)
```

*   **参数**：
    *   `before`：截断起始标签，保留此标签 **之后** 的数据（包含该标签）。
    *   `after`：截断结束标签，保留此标签 **之前** 的数据（包含该标签）。
    *   `axis`：操作轴，`0` 或 `'index'`（默认，行方向），`1` 或 `'columns'`（列方向）。
    *   `copy`：是否返回副本（默认为 `True`），若设为 `False` 则可能返回视图。
*   **返回值**：截断后的 DataFrame 或 Series。

我们来看几个示例：

```python
import pandas as pd

df = pd.read_csv('../student_scores.csv')

print(df.truncate(2, 5)) # 截取第2到第5行 默认行方向截取
print("----------")
print(df.姓名.truncate(2, 5)) # Series也可以截取
```
