# 函数的定义

## 定义

​	函数是执行特定任务的一段代码，程序通过将一段代码定义成函数，并为该函数指定一个函数名，这样就可以在需要的时候多次调用这段代码。

## 语法

```python
def 函数名(形参列表):
    函数体 (由零条道多条可执行语句组成的函数)
    return 返回值
```

**注意点：**

- 函数名要符合标识符定义，取名的时候要有意义，看名知义。 
- 形参列表是定义该函数可以接受的参数，多个参数都逗号隔开，调用函数的地方传入对应的参数值。
- return返回值，返回函数的执行结果。假如没有返回值，可以省略。

## 示例

```python
"""
    函数的定义
"""
# 定义最基础的函数 helloworld
def say_helloworld():
    print("Python你好")

# 调用函数
say_helloworld()

# 第二次调用函数
say_helloworld()

#======输出======
Python你好
Python你好
```
