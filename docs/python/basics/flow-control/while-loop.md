# while循环结构

循环语句可以在满足循环条件的情况下，反复执行某一段代码，这段被重复执行的代码被称为循环体。 当反复执行这个循环体时，需要在合适的时候把循环条件改为假，从而结束循环;否则循环将一直执行下 去，形成死循环。

## while循环语句语法格式

```python
初始化语句
while 循环条件:
    循环体
    迭代语句
```

- 初始化语句:一条或多条语句，用于完成一些初始化工作。初始化语句在循环开始之前执行。 
- 循环条件:这是一个布尔表达式，这个表达式能决定是否执行循环体。 
- 循环体:这个部分是循环的主体，如果循环条件允许，这个代码块将被重复执行。 
- 迭代语句:这个部分在一次执行循环体结束后，'对循环条件求值之前执行，通常用于控制循环条件 中的变量，使得循环在合适的时候结束。

**注意点:一定要有循环终止条件，否则会无限死循环，系统卡死。**

基本案例 1+2+3+...+10 求和 用while循环语句实现:

```python
"""
    while循环语句语法格式
    1+2+3+...+10 求和
"""
# 定义变量sum，用来保存运行过程中的累计和
sum = 0

# 定义变量i，循环过程每次被加的值
i = 1

while i <= 10:
    print(f"while执行第{i}次")
    # 进行累加
    sum += i
    # i每次执行加1
    i += 1
print(f"1+2+3+...+10的和是：{sum}")

#======输出======
while执行第1次
while执行第2次
while执行第3次
while执行第4次
while执行第5次
while执行第6次
while执行第7次
while执行第8次
while执行第9次
while执行第10次
1+2+3+...+10的和是：55
```



## while循环嵌套

我们在while循环内部还可以继续通过while循环来实现复杂得应用。

补充知识点:

- print()函数其实有个参数：print("", end="\\n")，`\n`是换行的意思，如果不想换行，删除`\n`即可

- 在字符串中，有一个特殊的符号 \t 这个是制表符 效果等同于在键盘上按下"TAB"键，所以 九九乘法表的每次打印最后，大家加下 end="\t"，这样格式就对齐好看了。

示例：打印二维的行列
```python
"""
    while循环嵌套
    打印二维的行列
"""
# 定义行
i = 1

# 打印5行
while i <= 5:
    print(f"打印第{i}行")
    # 定义列
    j = 1
    # 打印8列
    while j <= 8:
        print(f"打印第{j}列", end=" ")
        j += 1
    print()
    i += 1
print("打印完成")
```
