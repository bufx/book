# if条件分支结构

## 引入

如果 Python程序的多行代码之间没有任何流程控制，则程序总是从上向下依次执行。

但是现实生活中，我经常遇到一些需要做判断的业务流程。比如去银行ATM取款，如果密码输入正确， 则可以取款。如果密码输入错误，则提示让用户重新输入密码。

## 布尔类型和比较运算符

### 布尔类型

布尔( `bool`)表达现实生活中的逻辑，即真和假，`True`表示真，`False`表示假。

示例：
```python
"""
    布尔类型和比较运算符
"""
# 布尔类型定义
b1 = True
b2 = False
print(f"b1={b1}, 类型是{type(b1)}")
print(f"b2={b2}, 类型是{type(b2)}")

#======输出======
b1=True, 类型是<class 'bool'>
b2=False, 类型是<class 'bool'>
```

### 比较运算符

| 运算符 | 示例   | 说明                                            |
| ------ | ------ | ----------------------------------------------- |
| ==     | a == b | a和b值相等，结果是True，a和b值不相等结果为False |
| !=     | a != b | a不等于b结果为True，否则结果为True              |
| >      | a > b  | a大于b结果为True，否则为False                   |
| >=     | a >= b | a大于等于b结果为True，否则为False               |
| <      | a < b  | a小于b结果为True，否则为False                   |
| <=     | a <= b | a小于等于b结果为True，否则为False               |

比较运算符的返回结果，是布尔类型。

示例：

```python
# 比较运算符
n1 = 10
n2 = 20
print(f"n1==n2的结果是：{n1 == n2}")
print(f"n1!=n2的结果是：{n1 != n2}")
print(f"n1>n2的结果是：{n1 > n2}")
print(f"n1>=n2的结果是：{n1 >= n2}")
print(f"n1<n2的结果是：{n1 < n2}")
print(f"n1<=n2的结果是：{n1 <= n2}")

#======输出======
n1==n2的结果是：False
n1!=n2的结果是：True
n1>n2的结果是：False
n1>=n2的结果是：False
n1<n2的结果是：True
n1<=n2的结果是：True
```

## if语句语法格式

if语句基本语法格式

```python
if 判断条件 :
    执行内容..
```

**注意点:**

1. 第一判断条件后面要加冒号`:`
2. 第二 执行内容前面是四个空格
3. 第三 判断条件返回值是布尔类型

示例：
```python
"""
    if语句语法格式
    注意点:
    第一 判断条件后面要加冒号:
    第二 执行内容前面是四个空格
    第三 判断条件返回值是布尔类型
"""
age = input("请输入您的年龄：")
age = int(age)
print(f"我今年{age}岁了")
if age >= 18:
    print("已经成年")
print("我要好好学习，天天向上")

#======输出======
请输入您的年龄：19
我今年19岁了
已经成年
我要好好学习，天天向上

请输入您的年龄：16
我今年16岁了
我要好好学习，天天向上
```

## if else语句语法格式

```python
if 判断条件:
    满足条件执行内容...
else:
    不满足条件执行内容
```

**注意点:**

1. 第一 else后面要加冒号`:`
2. 第二 else 执行内容前面也是四个空格

示例：
```python
"""
    if-else语句语法格式
    注意点:
    第一 else后面要加冒号:
    第二 else 执行内容前面也是四个空格
"""
age = input("请输入您的年龄：")
age = int(age)
print(f"我今年{age}岁了")
if age >= 18:
    print("已经成年")
else:
    print("还未成年")
print("我要好好学习，天天向上")

#======输出======
请输入您的年龄：16
我今年16岁了
还未成年
我要好好学习，天天向上
```

## if elif else语句语法格式

当然有多个条件判断的时候，我们可以通过`if elif else`来实现

```python
if 条件1:
    条件1满足执行内容
elif 条件2:
    条件2满足执行内容
elif 条件n:
    条件n满足执行内容
else
    以上条件都不满足执行内容
```

示例：
```python
"""
    if elif else语句语法格式
"""
score = input("请输入您的成绩：")
print(f"我的成绩是：{score}分")
score = float(score)
if score >= 90:
    print("成绩优秀")
elif score >= 70:
    print("成绩良好")
elif score >= 60:
    print("成绩及格")
else:
    print("成绩不及格")
print("再接再励，加油！")

#======输出======
请输入您的成绩：90
我的成绩是：90分
成绩优秀
再接再励，加油！

请输入您的成绩：68.5
我的成绩是：68.5分
成绩及格
再接再励，加油！

请输入您的成绩：45.8
我的成绩是：45.8分
成绩不及格
再接再励，加油！
```

## if语句的嵌套应用

有时候业务上有多维度复杂条件判断，我们需要用到if语句的嵌套来实现。

举例:我们在一些游戏网站活动充值的时候，冲100送 20 冲200送50 但是vip用户的话，冲100送 30 冲200送70

```python
"""
    if语句的嵌套应用
"""
vip = False
amount = input("请输入充值金额：")
amount = int(amount)
if amount == 100:
    if vip:
        print("总共充值", 100 + 30)
    else:
        print("总共充值", 100 + 20)
elif amount == 200:
    if vip:
        print("总共充值", 200 + 70)
    else:
        print("总共充值", 200 + 50)

#======输出======
请输入充值金额：100
总共充值 120

请输入充值金额：200
总共充值 250
```
